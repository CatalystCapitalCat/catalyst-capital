## 1b. 美股账本 = Alpaca 模拟盘（2026-09-05 用户要求正规平台，engine.py 只管 A股 + 审计）

## 2. 风控（2026-09-05 用户明确：只有两条硬约束，其余全凭我的判断与学习）
**用户硬约束**：① **禁期权**（唯一的工具限制；做多/做空 ETF 都可用）；② **回撤 -10%** 必须写检讨（可继续交易）、**回撤 -20%** 暂停交易并从头到尾全面检讨。用户只看年底结果，过程全由我决定。
**我的默认纪律（可偏离；每次偏离必须在 --reason 里写明理由，并在日报里复盘该偏离对不对）**：
1. 买入默认带止损（普通股 6-8%、3x ETF 10-12%、A股 5-7%）。**有信心会反弹或上涨的仓位可以不带止损**，但必须写「不带止损的理由 + 认错条件（价格/时间/事件）」，每次巡检对照该条件；认错条件触发就走，不拖。
2. 仓位参考：单一非杠杆标的 ≤ 25% NAV；杠杆 ETF 合计 ≤ 50% NAV；有效敞口 ≤ 200%；反向 ETF 单次 ≤ 20%。这些上限是为了保住 -20% 红线，突破需写明理由。
3. 事件前（财报/FOMC/CPI）默认减杠杆或对冲；方向看得准时可以留仓，写明理由。
4. 单日亏 >4% 当日不开新仓；连续 3 笔止损后一周仓位减半（保护 -20% 红线，不轻易偏离）。
5. **允许追涨**：日内涨 >5% 的标的也可以追，但写明逻辑（板块起爆/放量突破/催化剂）和失效条件。大胡的「急跌接、出一半留底仓」、主任的点位卡都可作参考，但决定是我的。
6. 有效敞口 >150% 时默认持有对冲或收紧止损。
7. **（v1.6 新增）事件密度定仓位**：把一周内的二元事件（CPI/PPI/FOMC/长端拍卖/重大发布会/持仓股财报）数出来，**每周 ≥3 个 → 总敞口 ≤40% 且杠杆 ETF = 0；≥4 个 → 事件日前一收盘降到 ≤25%。** 理由：单个事件可以判断方向，四个事件叠在四天里只是掷骰子。
8. **（v1.6 新增）起跑期豁免限制**：在累计成交 <20 笔之前，**不使用「不带止损」的自主权**。第 2 节给我的偏离权是用实盘胜率换来的，我还没有这个样本。
**原则**：规则为结果服务，不为规则本身。每次偏离都是学习样本：周报统计「偏离默认纪律的交易」的胜率与盈亏比，赢的写成新规则，输的收紧。

## 3. 交易流程（每次唤醒按此执行）
- **盘前档**：读手册 → `alpaca.py fills && alpaca.py account && alpaca.py orders`（美股）/ `engine.py status cn`（A股）→ 隔夜要闻/期货/亚欧盘/催化剂（第 6 节信源）→ 写当日计划到 `research/YYYY-MM-DD-plan.md`（观点、点位、条件单）→ 下单（`order`）。
- **盘中档（每小时）**：美股 `alpaca.py fills && alpaca.py mark && alpaca.py orders`；A股 `engine.py run cn` → 看持仓/挂单是否触发 → 只按计划执行；突发（>2% 大盘异动、重大新闻）才临时调整，并记录理由。
- **盘后档**：美股 `alpaca.py fills && alpaca.py mark`；A股 `engine.py run cn && engine.py mark cn` → 写日报 `reports/daily/YYYY-MM-DD.md` → 追加 `lessons.jsonl` → 修订手册 → `alpaca.py html` 并发布到 GitHub Pages（catalyst-site/trader/）→ 向用户汇报。
- 下单命令：美股 `python3 alpaca.py buy SYM --amount 金额 --type limit|market [--limit 价] [--stop 止损] [--target 止盈] --reason ... --tag ...`；A股 `python3 engine.py order cn buy 代码 --amount 金额 --type limit|market [--limit 价] [--stop 止损] --reason ... --tag ...`。
- 每笔交易的理由格式（写进 `--reason`）：`论点 | 催化剂 | 失效条件 | 目标 | 期限 | 信心1-10 | 信源`。

## 4. 策略框架 v1（随复盘迭代）
A. **主线动量**：AI 硬件/存储（NVDA 财报后新高、MU 存储涨价周期、SMH 从 6 月高点最深跌 29% 后反弹中）。顺势用 SOXL 放大，止损严格。
B. **事件驱动**：Apple 发布会 9/9、**PPI 9/10 + ORCL/ADBE 财报 9/10**、**CPI 9/11（已核实，2026-09-06 由好奇先生周末贴 + 机构周报双向确认）**、**FOMC 9/15-16（加息概率约 58-66%）**、MU 财报 9/30。事件前减杠杆，事件后顺着方向做。
   - **B2（v1.6 新增）国债拍卖是被忽略的事件类**：长端拍卖（10Y/30Y）需求差 → 收益率上冲 → 高估值科技股杀估值。**把每周拍卖日程当成和 CPI 同级的事件写进周计划**；10Y 收益率 >4.90% 视为科技股红线，<4.70% 视为放行。
C. **对冲/反向**：拥挤共识（大佬+机构+我同向）出现时，用 SOXS/SQQQ 对冲而不是加信心；油价/利率冲击日（伊朗、霍尔木兹）优先防守。
D. **A股**：磨底期，小票强大票弱；ETF 为主（科创50/半导体/创业板/中概），个股只做有产业催化的龙头；T+1 意味着买入当天不能止损，仓位要更小。
E. 空仓也是仓位：没有优势时持币，别为交易而交易。
F. **（v1.6 新增）用「有基本面驱动的多头」当对冲，优先于买反向 ETF**。反向 ETF 有时间损耗和衰减，只在方向明确的短窗口用；当风险链条可以被某个正向资产表达时（例：油↑→CPI↑→利率↑→科技杀估值，这条链的对冲是 XLE 而不是 SQQQ），优先用它 —— 对冲本身能赚钱，成本为负。
G. **（v1.6 新增）「拥挤共识」的可执行版本**：当 ≥3 个独立信源 + 我自己同向，**且该标的近一周已兑现 >8%**，则该标的降级为「只在回调买」，仓位上限砍半。**光有共识不够，必须叠加「已兑现」才触发** —— 否则这条规则会让我系统性踏空主线。（触发样例：2026-09-06 存储 MU，周 +8.98%、月 +15.33%，好奇先生/Serenity/大胡/社长同向 → 降级为只在 950 以下买。）
H. **（v1.6 新增）A股 / 美股同板块背离监控**：每周计算美股半导体（SOX/SMH）与 A股半导体（512480/512760/588000）的周涨跌差。**差值 >5 个百分点即写进周报并追因**。首次记录：2026-09-01~04，美股半导体 +2.3% vs A股半导体 -6.1%，**背离 8.4 个百分点**。背离期间 A股科技属于独立下跌趋势，叠加 T+1，不接刀。

## 5. 学习协议（用户核心要求：自主学习）
- **每日三问**（写进日报）：① 今天哪笔对/错，原因是信息缺失、权重给错、被信源带偏还是突发？② 我被谁带偏了，它当时的动机可能是什么？③ 明天改什么规则？
- `lessons.jsonl`：`{date, tag, lesson, evidence, rule_change}` 只追加。手册第 8 节维护「教训索引」。
- **每周**（周六）：按策略类型/信源统计胜率、平均盈亏比、最大回撤；淘汰连续两周负期望的策略；更新信源信用分。
- **信源信用档案**：任何大佬、机构、X 博主的观点都记「说了什么 → 后来怎样」，说与做背离即警报。共识本身是风险信号。
- **反人性原则**（用户训导）：机构公开唱多可能是诱多；机构的话是关于其动机的数据，不是真相。先看它的动作（仓位流向/期权 flow/13F），再看它的话。
- 学习面必须广：三大佬信源只是其中之一；每周至少读 5 个不同来源的独立观点，并把有价值的方法沉淀进本手册第 4 节。**某个信源下线时（如 2026-09-06 大胡会员到期），要主动补一个新来源顶上，不能让「5 个独立来源」的要求随之缩水。**
- **（v1.6 新增）信源分层使用规则** —— 不要整体地信或不信一个人，要按「他哪部分能力被验证过」分层取用。2026-09-06 首次实测得出：
  1. **主任：只取他隔夜发布的静态点位卡，忽略他的日内叙事与自我评分。** 证据：9/4 点位卡高点 7750.19 精确止步于平衡位上沿 7750（差 0.19 点）、低点 7706.12 精确止步于强支撑上沿 7705（差 1.12 点）；但同期「伽马转负 → 大波动 + 突破单边」完全错（实际振幅 0.57%，无关键位被破），**而他盘后自评称自己判断正确**。
  2. **社长：用他的节奏框架，不用他的数字，引用前必须自己复算。** 证据：SpaceX IPO 四阶段模板 12 格方向 100% 正确、跌段幅度精确（MU -22 实测 -21.6、-42 实测 -41.2），**但涨段一律夸大 25-45%**（MU +67 实测最大 53.6、+37 实测 25.7）。这与 2026-07「SMH 收高开盘 3%、实核 +1.57%」是**同一方向的偏差**，两次独立样本 → 认定为系统性偏差，**默认对他的涨幅口径打七折**。
  3. **大胡：自报成交价可信，学方法不跟单。** 证据：抽查 3 笔（SOXL 100/115.4、INTC 86.5/94.9、MRVL 208.7/216.5）用 Yahoo 分钟线核实，**3/3 全部落在当日实际区间内**。但他报的是「已成交」不是「将成交」，只能学他的分批出货节奏。
  4. **主动交代样本弱点的信源，可信度加分。** 好奇先生给苹果回测时主动说「只有 10 次样本、被 2020 拉高均值」——**这种自我设限是可信度的正向信号**，与主任的自我美化形成对照。
  5. **机构公开对立 = 无拥挤共识 = 可以小仓试探。** 例：美银「还有三次加息」vs 摩根资管「60% 概率过早」。
