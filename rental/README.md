## 户型图是怎么推断的

- **确定的连接**（视频里直接走过）：一层入口 → 楼梯 → 楼梯口 → 走廊 → 厨房；走廊尽头右侧进客厅；大厅有两个门洞（A 在楼梯口旁，B 在走廊尽头）；大厅北墙木门 C 通后厅；卫生间与卧室紧挨着，位于走廊尽头一侧。
- **推测的部分**：客厅里一扇未开启的木门，按位置推测通厨房；卫生间和卧室之间那段小过道是根据镜头转换补的；后厅另一侧的门洞去向没拍到；各房间尺寸、面积、朝向均为目测估算。
- 图中所有面积标注均带“约”，比例尺也是估算。

## 图片处理说明

- 从全部 2,799 帧里按清晰度评分挑选，每个房间取 2–4 张时间点不重复的最清晰帧。
- 处理步骤：轻度降噪 → 温和白平衡（限幅，避免偏色） → 暗房间提亮 gamma ≤ 1.7 → 局部对比度轻微增强 → FSRCNN 2 倍超分（956×1700） → 轻微锐化。
- **没有做的事**：没有增删家具、没有修掉墙面水渍霉斑、没有改变任何结构。卧室墙面的霉斑是真实现状，建议出租前处理。
- 视频中未出现人脸、门牌、证件等隐私信息，未做打码。
