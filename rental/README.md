## 户型图是怎么得出的

第一版户型图仅凭肉眼看关键帧推断，被指出全错后改用以下方法重做：

1. 对全片抽帧做 COLMAP 三维重建（穷举匹配），得到相机轨迹与墙面点云。主模型把楼梯、楼梯口、走廊、厨房、大厅、门C、卫生间注册进同一坐标系。
2. 用重建结果核对每个门洞的位置，再对关键转场逐帧检查镜头转向。
3. 结论与第一版的差异：
   - 之前画成两个门洞的“门A”“门B”其实是同一个门洞D，位于楼梯口，0:24 从外往里看、0:59 从走廊回来走进去都是它。
   - 大厅在走廊的另一侧（与楼梯井相对），是一个长方形：门洞D与门C在两端，三扇窗在同一面长墙。
   - 卫生间和卧室不在走廊尽头，而是在大厅另一端门C后面的小过道里。1:15 镜头由门C进过道右拐入卫生间，中间没有剪辑；1:24 出卫生间直接进卧室。
4. 仍属推测的部分：厨房和客厅各有一扇未开启的门的去向；卧室是否有第二扇窗；各房间尺寸与面积（目测估算）；真实朝向。

## 图片处理说明

- 从全部 2,799 帧里按清晰度评分挑选，每个房间取 2–4 张时间点不重复的最清晰帧。
- 处理步骤：轻度降噪 → 温和白平衡（限幅） → 暗房间提亮 gamma ≤ 1.7 → 局部对比度轻微增强 → FSRCNN 2 倍超分（956×1700） → 轻微锐化。
- **没有做的事**：没有增删家具、没有修掉墙面水渍霉斑、没有改变任何结构。卧室墙面的霉斑是真实现状。
- 视频中未出现人脸、门牌、证件等隐私信息，未做打码。
